# Data Analytics Portfolio

Three end-to-end projects covering SQL, Python machine learning, R visualisation and SPSS survey statistics, each framed around a Kenyan business or policy question.

| # | Project | Tools | Headline result |
|---|---|---|---|
| 1 | [Predicting Mobile-Loan Default](01_sql_python_loan_default/) | SQL (SQLite), Python, scikit-learn | ROC-AUC 0.775 out-of-time; reviewing the riskiest 20% of loans catches 54% of defaults |
| 2 | [Kenya's Economy 2000–2025 Dashboard](02_r_kenya_economy/) | R, ggplot2, patchwork, World Bank data | Six-panel statistical dashboard; inflation volatility fell from 5.9 to 1.3 points |
| 3 | [Survey Analysis Case Study](03_spss_survey_case_study/) | SPSS syntax, Python (statsmodels) | Financial literacy, not education, drives formal saving (OR 2.4) |

## Data honesty

- **Project 2 uses real public data** (World Bank WDI).
- **Projects 1 and 3 use simulated data**, generated by seeded scripts included in each folder, because real loan and survey microdata are confidential. Each README says so. Be upfront about this in interviews; it's normal for portfolio work, and you can explain how you would swap in real data (e.g. a KNBS/FinAccess survey for Project 3).
